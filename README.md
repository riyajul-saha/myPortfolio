## 📖 Overview

Welcome to the source repository for **[Riyajul Saha](https://riyajulsaha.is-a.dev/)**'s official portfolio website.

Engineered with full-stack capabilities using **TanStack Start**, **React 19**, and **Tailwind CSS v4**, this portfolio delivers blazing-fast performance, sub-millisecond route transitions, and responsive fluidity across every device. Built from the ground up with a **dark-first aesthetic** utilizing the **OKLCH color space** and sleek violet accents, the site showcases flagship work across full-stack commerce platforms, cross-platform mobile apps (React Native / Expo), and applied machine learning systems.

### 🌟 Highlights

- **⚡ Sub-Millisecond Speed**: Hybrid SSR and SPA architecture backed by Nitro server engine and Vite 8 bundler.
- **🛡️ 100% Type-Safe Routing**: File-based routing with TanStack Router, supporting dynamic case-study routes (`/projects/:slug`) and smooth modal overlays.
- **🎨 Modern Dark Design System**: Crafted with OKLCH color tokens, glassmorphism, responsive navigation drawers, and Plus Jakarta Sans typography.
- **📈 Comprehensive SEO**: Schema.org JSON-LD graphs (Person, WebSite, SoftwareApplication, CreativeWork), automated XML sitemaps, Open Graph cards, and robots indexing.
- **♿ Accessible UI Primitives**: Built on headless Radix UI components with polished micro-interactions and smooth scroll animations.

## 🛠️ Tech Stack & Architecture

```
┌────────────────────────────────────────────────────────────────────────┐
│                        Riyajul Saha Portfolio                          │

│ 🌐 Deployment Platform           │ Vercel Edge Network                 │
└──────────────────────────────────┴─────────────────────────────────────┘
```

### **Detailed Breakdown**

- **Framework & Core**:
  - **[React 19](https://react.dev/)**: Latest release featuring Actions, modern concurrent rendering, and optimized ref handling.
  - **[TanStack Start](https://tanstack.com/start)**: Full-stack React framework built on TanStack Router and Nitro.
  - **[TanStack Router](https://tanstack.com/router)**: 100% type-safe file-based router with built-in search params management.
  - **[TypeScript](https://www.typescriptlang.org/)**: Strict static typing across routes, portfolio data models, and UI components.
  - **[Nitro](https://nitro.build/)**: Universal server engine providing fast edge and Node.js runtime portability.

- **Styling & Presentation**:
  - **[Tailwind CSS v4](https://tailwindcss.com/)**: CSS-first configuration via `@tailwindcss/vite` utilizing inline theme tokens and OKLCH color scales.
  - **[Radix UI](https://www.radix-ui.com/)**: Accessible headless primitives for modals, dialogs, tooltips, and tabs.
  - **[Lucide React](https://lucide.dev/)**: Consistent, lightweight vector iconography.
  - **[Embla Carousel](https://www.embla-carousel.com/)**: Fluid, hardware-accelerated touch carousel.

- **Validation, Forms & Tools**:
  - **[React Hook Form](https://react-hook-form.com/) & [Zod](https://zod.dev/)**: Client-side form validation schema and state management.
  - **[Web3Forms](https://web3forms.com/)**: Seamless, zero-backend contact form submission delivery.
  - **[Sonner](https://sonner.emilkowal.ski/)**: Polished and responsive toast notifications.
  - **[Vite 8](https://vite.dev/)**: Lightning-fast local development server and optimized rollup production bundling.

## 🚀 Getting Started

Follow these steps to run the portfolio locally on your workstation.

### Prerequisites

Ensure you have the following installed on your machine:

- **Node.js**: `v20.0.0` or higher ([Download Node.js](https://nodejs.org/))
- **npm**: `v10.0.0` or higher (bundled with Node.js)
- **Git**: Installed and configured ([Download Git](https://git-scm.com/))

### Installation & Local Setup

1. **Clone the repository:**

   ```bash
   git clone https://github.com/riyajul-saha/myPortfolio.git
   cd myPortfolio
   ```

2. **Install project dependencies:**

   ```bash
   npm install
   ```

3. **Configure Environment Variables (Optional):**
   Create a `.env` file in the root directory if you want to use your own Web3Forms key:

   ```env
   VITE_WEB3FORM_ACCESS_KEY="your-web3forms-access-key-here"
   ```

   _(A fallback key is already provided for local testing.)_

4. **Start the local development server:**

   ```bash
   npm run dev
   ```

5. **Open in your browser:**
   ```
   http://localhost:8080
   ```

## 🌐 Deployment

This project is configured for one-click deployment on **[Vercel](https://vercel.com/)** with zero-config SSR support via Nitro and `vercel.json`:

### Option 1: Vercel Dashboard (Recommended)

1. Push your repository to GitHub.
2. Import the repository in [Vercel Dashboard](https://vercel.com/new).
3. Vercel automatically detects **TanStack Start** and configures the build command (`npm run build`).
4. Click **Deploy**.

### Option 2: Vercel CLI

```bash
# Install Vercel CLI globally
npm install -g vercel

# Deploy directly from terminal
vercel
```
